# Recursos visuales

Para conservar exactamente la fotografía del portfolio anterior, copia aquí
la fotografía original con el nombre `joel.jpg` (cuando tengas el proyecto
LaVidaDeJoel.zip) y sustituye el `CircleAvatar` de `lib/widgets/presentacion.dart`
por un `ClipOval` con `Image.asset('assets/images/joel.jpg')`. Descomenta
`assets` en `pubspec.yaml`.

La cancha de bienvenida se dibuja de forma vectorial en
`lib/widgets/cancha_fondo.dart` basándose en las capturas del diseño. Se puede
sustituir por la imagen original si se aporta el recurso de la práctica 1.

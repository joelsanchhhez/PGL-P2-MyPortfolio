# Capturas de la Tarea 5

Las cuatro imágenes `tarea5_*.png` corresponden a la versión simplificada según
los apuntes, ejecutada en Android Pixel 9 (540 × 1212) el 19 de noviembre de 2026.
Las alertas muestran respuestas reales de `https://my-users-api.onrender.com`.
Se utilizó una cuenta ficticia y la contraseña está oculta.

- `tarea5_registro_exitoso.png`: registro aceptado y posterior vuelta al login.
- `tarea5_login_fallido.png`: contraseña incorrecta rechazada.
- `tarea5_login_exitoso.png`: login correcto y JWT guardado de forma segura.
- `tarea5_bienvenida_api.png`: respuesta del endpoint protegido de bienvenida.

También se verificaron en el emulador la restauración del token, el cierre de
sesión, el bloqueo de rutas privadas y la eliminación de un token inválido.
Los archivos temporales usados para comprobarlo no forman parte de la entrega.
Las otras imágenes de esta carpeta pertenecen a las tareas anteriores.
